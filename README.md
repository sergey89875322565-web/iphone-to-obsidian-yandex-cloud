# iPhone → Obsidian через Yandex Cloud: голосовые заметки с расшифровкой

Конвейер «записал на диктофон → получил текст с разметкой спикеров в Obsidian»,
собранный из стандартных компонентов: iOS «Команды», Yandex Cloud Function,
Object Storage и SpeechKit v3 (асинхронное распознавание с диаризацией).

Тап по «Поделиться» в Диктофоне → запись улетает в облако → локальный скрипт
(по расписанию или вручную) забирает её, распознаёт через SpeechKit и создаёт
markdown-заметку в вашем хранилище Obsidian с тайм-кодами и спикерами.

## Схема потока

```
 iPhone                                   Yandex Cloud                       Локальная машина
┌──────────────┐   «Поделиться»   ┌────────────────────┐   presigned   ┌──────────────────────┐
│  Диктофон    │ ───────────────▶ │  Шорткат «Команды» │ ── GET ─────▶ │ Cloud Function       │
│  (m4a и др.) │                  │                    │  ?token&name  │ (webhook, SigV4      │
└──────────────┘                  │  1. GET → функция  │               │  вручную, без boto3) │
                                  │  2. PUT → S3       │ ◀── text ──── └─────────┬────────────┘
                                  └─────────┬──────────┘  presigned URL           │ подписывает PUT
                                            │ PUT файла                           ▼
                                            ▼                            ┌──────────────────────┐
                                  ┌──────────────────────┐               │ Object Storage       │
                                  │  s3://<BUCKET>/      │ ◀──────────── │  (бакет, префикс     │
                                  │  inbox/YYYY-MM-DD/…  │   загрузка    │  inbox/)             │
                                  └─────────┬────────────┘               └──────────────────────┘
                                            │ list/download
                                            ▼
                                  ┌────────────────────────────────────────────────────────┐
                                  │ sync/meetly-speechkit-sync.py (cron / Task Scheduler): │
                                  │  1. скачать запись из inbox/                           │
                                  │  2. WAV 16k mono (ffmpeg)                              │
                                  │  3. SpeechKit v3 async + speakerLabeling               │
                                  │  4. заметка в Obsidian: «<дата> — <имя>.md»            │
                                  │  5. объект → inbox-processed/                          │
                                  └────────────────────────────────────────────────────────┘
                                            │
                                            ▼
                                  Obsidian vault → заметка с тайм-кодами и «Спикер 1/2»
```

## Состав репозитория

| Путь | Что это |
|---|---|
| `cloud-function/index.py` | HTTP-приёмник: проверяет токен, возвращает presigned PUT URL простым текстом |
| `shortcut/README.md` | Пошаговая сборка шортката iOS «Команды» |
| `sync/meetly-speechkit.py` | Движок распознавания: WAV → Object Storage → SpeechKit v3 async → сегменты со спикерами |
| `sync/meetly-speechkit-sync.py` | Оркестратор: inbox → расшифровка → заметка в Obsidian (идемпотентен) |
| `.env.example` | Список всех нужных переменных окружения |

## Пререквизиты

- **Аккаунт Yandex Cloud** с платёжным аккаунтом.
- **Object Storage**: бакет + статический ключ сервисного аккаунта
  (роль `storage.editor` на бакет).
- **Cloud Function** (публичная) в том же каталоге.
- **API-ключ SpeechKit** (сервисный аккаунт с ролью `ai.speechkit.user` или
  `ai.languageModels.user` — API-ключ, не IAM: передаётся как `Api-Key`).
- **iPhone** с предустановленным приложением «Команды».
- На локальной машине: **Python 3.10+**, `pip install boto3 imageio-ffmpeg`,
  **Obsidian vault** с папкой для заметок.

## Настройка

### 1. Object Storage

1. Создайте бакет (например, `my-voice-inbox`).
2. Создайте сервисный аккаунт, дайте ему `storage.editor` на каталог/бакет.
3. Выпустите **статический ключ доступа** — получите `key_id` и `secret`.
   Они понадобятся и функции, и локальному скрипту.

### 2. Cloud Function (webhook)

1. Создайте функцию (Python 3.11+), код — из `cloud-function/index.py`.
   Точка входа: `index.handler`. Таймаут: 10 с хватит. Память: 128 МБ.
2. Сделайте функцию **публичной** (токен в URL — единственная защита,
   придумайте длинную случайную строку: `openssl rand -hex 16`).
3. Переменные окружения функции:

   | Переменная | Значение |
   |---|---|
   | `INBOX_TOKEN` | ваш секретный токен (тот же будет в URL шортката) |
   | `S3_KEY_ID` | `key_id` статического ключа |
   | `S3_SECRET` | `secret` статического ключа |
   | `BUCKET` | имя бакета |

4. Проверьте в браузере:
   `https://functions.yandexcloud.net/<FUNCTION_ID>?token=<TOKEN>&name=test.m4a`
   — должна вернуться длинная ссылка `https://<BUCKET>.storage.yandexcloud.net/inbox/...?X-Amz-...` простым текстом.

### 3. Шорткат на iPhone

Соберите шорткат по инструкции в `shortcut/README.md` (≈3 минуты, 7 действий).
Понадобятся `<FUNCTION_URL>` и `<TOKEN>` из шага 2.

### 4. Локальный скрипт синхронизации

```bash
pip install boto3 imageio-ffmpeg
cp .env.example .env   # заполните значениями
export $(grep -v '^#' .env | xargs)        # Linux/macOS
# Windows PowerShell: Get-Content .env | % { $n,$v = $_ -split '=',2; [Environment]::SetEnvironmentVariable($n,$v) }

python sync/meetly-speechkit-sync.py --dry-run   # посмотреть, что будет обработано
python sync/meetly-speechkit-sync.py             # реальный прогон
```

Поставьте запуск по расписанию: cron (`37 21 * * *`) или Планировщик задач
Windows. Скрипт идемпотентен — повторные запуски обрабатывают только новые
объекты; обработанные переносятся из `inbox/` в `inbox-processed/`.

## Стоимость (ориентиры Yandex Cloud, прайс на конец 2025)

- **SpeechKit async**: ~150 ₽ за час аудио (≈0,8–2,5 ₽/мин в зависимости от
  модели) — основная статья расходов.
- **Cloud Functions**: первый миллион вызовов/мес бесплатно; наш вызов — копейки.
- **Object Storage**: хранение ~2 ₽/ГБ/мес, операции PUT/GET — доли копейки.
  Записи из inbox можно чистить lifecycle-правилом.

Часовая запись встречи обойдётся примерно в **150 ₽**; короткие голосовые
заметки — рубли.

## Ограничения

- Функция публичная: безопасность = секретность токена. Не коммитьте `.env`,
  ротируйте токен при утечке (поменять в env функции и в шорткате).
- Presigned URL живёт 1 час — шорткат использует его сразу.
- Распознавание: ru-RU, модель `general:rc`; диаризация SpeechKit даёт
  безымянные метки «Спикер 1/2» — переименовывайте вручную.
- Форматы аудио: m4a, mp3, wav, ogg, aac, mp4, flac, caf, aiff, opus.
- Тайм-зона в заметках жёстко +3 (МСК) — поменяйте под себя
  (`MSK_OFFSET_HOURS` в sync-скрипте).
- Если телефон офлайн — шорткат упадёт; запись останется в Диктофоне,
  отправьте позже.
