# Шорткат iOS «Команды»: отправка записи одним тапом

Шорткат получает аудиофайл из меню «Поделиться», запрашивает у Cloud Function
presigned URL и делает PUT файла в Object Storage. Время сборки — ≈3 минуты.

Понадобятся (см. корневой README, шаг 2):

- `<FUNCTION_URL>` — адрес функции вида `https://functions.yandexcloud.net/<FUNCTION_ID>`
- `<TOKEN>` — значение `INBOX_TOKEN` из переменных окружения функции

## Сборка (один раз)

Точный путь: приложение **«Команды»** (фиолетовая иконка, предустановлено;
если удалено — App Store → «Команды» от Apple). Всё делается там,
а не в «Настройках».

1. Откройте **«Команды»** → вкладка **«Команды»** внизу слева → кнопка **«+»**
   в правом верхнем углу.
2. Вверху по центру тапните по названию «Новая команда» → **«Переименовать»** →
   введите, например, **«Отправить запись в Obsidian»**.
3. Подключите шорткат к меню «Поделиться»: внизу редактора есть полоска
   значков — **(i) в кружочке**, «Поделиться» и синяя кнопка Play ▶.
   Тапните **«(i)»** → включите переключатель **«На странице экспорта»**
   (в старых iOS — **«В меню "Поделиться"»**, это одно и то же) → сохраните
   галочкой ✓.
   В начало шортката добавится блок **«Получать [Любые] из страницы
   экспорта»** — тапните «Любые» → **«Снять выбор со всех»** → отметьте
   только **«Файлы»** и **«Медиа»**.

   ⚠️ Этот переключатель живёт ТОЛЬКО в «(i)». В поиске действий его нет —
   «Поделиться через приложения» и «Отправить сообщение» из поиска НЕ
   подходят, это обычные действия.

4. Добавьте действия (кнопка **«Добавить действие»** или строка поиска внизу —
   вводите названия по-русски, ПО ОДНОМУ):

   | # | Действие | Настройка |
   |---|---|---|
   | 1 | **Получить имя** | из «Входные данные команды» |
   | 2 | **Текст** | `<FUNCTION_URL>?token=<TOKEN>&name=` + переменная «Название» из шага 1 (таблетка из панели над клавиатурой) |
   | 3 | **URL** | вход «Текст» (подставится сам; действие «URL» само кодирует кириллицу — отдельное «Кодировать URL» НЕ нужно, оно ломает ссылку, кодируя `?`) |
   | 4 | **Получить содержимое URL** | вход «URL» из шага 3; метод GET; вернёт presigned-ссылку простым текстом |
   | 5 | **URL** | вход — переменная «Содержимое URL» из шага 4 |
   | 6 | **Получить содержимое URL** | вход — переменная «URL» из шага 5; стрелка › → метод **PUT** → «Тело запроса» = **Файл** → переменная «Входные данные команды» |
   | 7 | **Показать уведомление** | «Запись отправлена» |

   ⚠️ Красная таблетка-переменная = битая ссылка (действие-источник удалили).
   Лечится повторным выбором: тапните таблетку → «Выбрать переменную».
   ⚠️ Если действие «URL» добавилось с текстом `apple.com` — это значение
   по умолчанию, замените его на нужную переменную.

5. Сохраните: кнопка **«Готово»** в правом верхнем углу.

## Как пользоваться

**Диктофон** → тап по записи → **«…»** → **«Поделиться»** → выберите ваш
шорткат → дождитесь уведомления (1–3 сек на Wi-Fi).

Если шортката не видно в меню «Поделиться»: пролистайте действия до конца
вниз → **«Изменить действия…»** → найдите шорткат и включите его.

**Имя файла диктофона становится названием заметки** — переименовывайте
запись ДО отправки (в Диктофоне: тап по названию).

## Замечания

- Токен зашит в URL внутри шортката. Шорткаты синхронизируются через iCloud —
  не публикуйте скриншоты с URL и не делитесь шорткатом ссылкой.
- Presigned URL живёт 1 час — шорткат использует его сразу, это нормально.
- Если телефон офлайн — шорткат упадёт с ошибкой; запись останется в Диктофоне,
  отправьте позже.
